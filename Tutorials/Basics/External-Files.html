GitHub + External Files

In Browser (Quick Use)

  1. Go to GitHub and create an account
  2. Create a repository
  3. Click "Add File" → "Upload Files"
  4. Click "Upload" to choose from a folder, or drag and drop the uploaded files.


Tips

  • Open it in a code editor to be able to easily manage or edit your files. See more at Adobe Dreamweaver or VS Code
