GitHub + JavaScript

In Browser (Quick Use)

  1. Go to GitHub and create an account
  2. Create a repository
  3. Click "Add File" → "Create New File" and name it any name with the .js extension e.g script.js
  4. Write your code, add a commit message, and click "Commit Changes"


In A Code Editor (Recommended)

  1. Go to GitHub and create an account
  2. Create a repository
  3. Initialize it with your preferred editor: VS Code, Adobe Dreamweaver, etc.

Tips

  • Add a gitignore for JS to help GitHub understand your code better.
  • Use this with HTML & CSS to make a well-made website.
