GitHub + Java

In Browser (Quick Use)

  1. Go to GitHub and create an account
  2. Create a repository
  3. Add a Java .gitignore
  4. Click "Add File" → "Create New File" and name it anything with the .java extension e.g main.java
  5. Write your code, add a commit message, and click "Commit Changes"


In A Code Editor (Recommended)

Setting it up

  1. Go to GitHub and create an account
  2. Create a repository
  3. Add a Java .gitignore
  4. Click "Code" → Copy the HTTPS
  5. Download IntelliJ IDEA (Or a different code editor)
  6. Download a JDK like Adoptium (Install it on local disk)
  7. Open IntelliJ
  8. Click "Clone Repository"
  9. Paste the HTTPS link
  10. Choose a folder location
  11. Click "Clone"
  12. Click "IntelliJ IDEA" → "Settings"
  13. Type "jdk" in the top left search bar
  14. Click "Importing"
  15. Choose the jdk you downloaded for "JDK For Importer"


Pushing to GitHub

  1. Click "Git" → Commit at the top (or press the icon in the left that looks like a circle with lines through it)
  2. Select the files to commit
  3. Add a commit message (summary) about your changes
  4. Click "Commit and Push"
