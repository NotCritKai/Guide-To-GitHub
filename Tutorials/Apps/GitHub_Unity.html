GitHub + Unity

Project Setup

  1. Go to GitHub and make an account
  2. Create a repository
  3. Click "Code" and copy the HTTPS link
  4. Add the Unity .gitignore when creating the repository
  5. Download GitHub Desktop and sign in
  6. Click "Clone Repository", or go to "File" → "Clone Repository"
  7. Click "URL" and paste the HTTPS link
  8. Choose a folder location
  9. Click "Clone"
  10. Navigate to the cloned folder and open the .gitignore file (on macOS, press CMD + Shift + . to show hidden files)




  1. Remove the slashes from the first few lines of the .gitignore
  2. Save the file




  1. Download Unity Hub
  2. Click "Installs" → "Install Editor" and download the latest version
  3. Create a new project
  4. Set the project location to inside the cloned repository folder


Pushing / Pulling from GitHub

  1. After making changes, save them
  2. Open GitHub Desktop
  3. Click "Fetch Origin"
  4. Add a commit message and click "Commit to main"
  5. Click "Push Origin"
