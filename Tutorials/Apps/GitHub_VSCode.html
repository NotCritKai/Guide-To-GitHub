Pushing to GitHub

  1. Click on the Source Control icon in the left toolbar (looks like a branch)
  2. Click the folder icon (looks like a folder with a branch) to stage files
  3. Select the files you want to commit
  4. Click the circle with a line through it to stage changes
  5. Type a message summarising what you did
  6. Click "Commit"
  7. Click the sync icon (book with an upward arrow) to push
