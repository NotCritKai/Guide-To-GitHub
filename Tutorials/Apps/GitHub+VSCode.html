Pushing to GitHub

  1. Click on the icon in the toolbar on the right (looks like a branch)
  2. Click on the folder icon in the toolbar on the right (looks like a folder with a branch)
  3. Select the files you want to commit
  4. Click on the circle with a line going through it
  5. Type a message (summary) of what you did
  6. Click "Commit"
  7. Click on the book with an arrow going up
