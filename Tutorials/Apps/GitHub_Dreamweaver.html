GitHub + Adobe Dreamweaver

Setting It Up

  1. Go to GitHub and make an account
  2. Create a repository
  3. Buy/Download Dreamweaver (paid)
  4. Click "Code" and copy the HTTPS link
  5. Open Dreamweaver
  6. At the top, click "Site" → "New Site"
  7. Name your site and choose a file location
  8. Click "Associate A Git Repository With This Site"
  9. Click "Clone Existing Git Repository Using URL"
  10. Paste the HTTPS link
  11. If needed, enter your GitHub credentials
  12. Click "Save"


Pushing to GitHub

  1. Click on the Git icon in the left toolbar (looks like a branch)
  2. Type a commit message summarising what you did
  3. Click "Commit"
  4. Click "Push"
