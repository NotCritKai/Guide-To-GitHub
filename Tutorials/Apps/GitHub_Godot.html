GitHub + Godot

Project Setup

  1. Go to GitHub and make an account
  2. Create a repository
  3. Click "Code" and copy the HTTPS link
  4. Download GitHub Desktop and sign in
  5. Click "Clone Repository", or go to "File" → "Clone Repository"
  6. Click "URL" and paste the HTTPS link
  7. Choose a folder location
  8. Click "Clone"
  9. Download Godot
  10. Create a project and set its location to inside the cloned repository folder


Pushing / Pulling from GitHub

  1. After making changes, save them
  2. Open GitHub Desktop
  3. Click "Fetch Origin"
  4. Add a commit message and click "Commit to main"
  5. Click "Push Origin"
