GitHub + Godot

Project Setup

  1. Go to GitHub and make an account
  2. Create a repository
  3. Click "Code" and copy the HTTPS link
  4. Download GitHub Desktop and sign in
  5. Click "Clone Repository" or go to the top and click "File" → "Clone Repository"
  6. Click "URL" or Choose a repository to clone
  7. Paste the HTTPS link
  8. Choose a folder
  9. Click "Clone"
  10. Download Godot
  11. Make a project and choose the project location to be inside of the cloned repository folder


Pushing / Pulling from GitHub

  1. After making changes, save them
  2. Open GitHub Desktop
  3. Click "Fetch Origin"
  4. Add a "Commit" (Summary) message, and click "Commit _ files to main"
  5. Then click "Push Origin"
