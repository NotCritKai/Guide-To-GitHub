GitHub + Unity

Project Setup

  1. Go to GitHub and make an account
  2. Make a repository
  3. Click "Code" and copy HTTPS
  4. Add the Unity gitignore
  5. Download GitHub Desktop and sign in
  6. Click "Clone Repository" or go to the top and click "File" → "Clone Repository"
  7. Click "URL" or Choose a repository to clone
  8. Paste the HTTPS link
  9. Choose a folder
  10. Click "Clone"
  11. Go to the file location and open the gitignore (if your on MacOS you need to press CMD + Shift + .




  1. Remove the slashes from the first few lines
  2. Save




  1. Download Unity
  2. Click "Installs" → "Install Editor" and download the latest version
  3. Create a project
  4. Choose the project location to be inside of the cloned repository folder

Pushing / Pulling from GitHub

  1. After making changes, save them
  2. Open GitHub Desktop
  3. Click "Fetch Origin"
  4. Add a "Commit" (Summary) message, and click "Commit _ files to main"
  5. Then click "Push Origin"
