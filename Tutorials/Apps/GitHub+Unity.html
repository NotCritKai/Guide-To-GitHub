GitHub + Unity

  2. Make a repository
  3. Click "Code" and copy HTTPS
  4. Add the Unity gitignore
  5. Download GitHub Desktop and sign in
  6. Click "Clone Repository" or go to the top and click "File" → "Clone Repository"
  7. Click "URL" or Choose a repository to clone
  8. Paste the HTTPS link
  9. Choose a folder
  10. Click "Clone"
